# Guía de publicación en GitHub

## Repositorio
El código y la documentación están en `https://github.com/oarangos-rgb/Icommerce`.

## Wiki de GitHub
La carpeta `wiki/` dentro del repositorio contiene documentación en Markdown, pero **no es automáticamente la Wiki independiente de GitHub**.

Para publicarla en la pestaña Wiki:
1. En el repositorio, abre `Settings → General → Features` y activa `Wikis`.
2. Abre la pestaña `Wiki` y crea la página inicial `Home`.
3. Copia los archivos Markdown de `wiki/` a las páginas correspondientes. Para importarlos todos, se puede clonar el repositorio Git independiente de la Wiki y enviar los cambios allí.
4. Añade imágenes desde la carpeta `wiki/imagenes/` o enlázalas mediante sus URL de GitHub.

La dirección final será `https://github.com/oarangos-rgb/Icommerce/wiki` cuando la Wiki esté creada.
